# Glosario neutral

El código usa estos nombres mientras no exista la temática final. Los nombres que ve el jugador están en `textos/es.json`; para re-tematizar basta con cambiar ese archivo.

| Término neutral | En el código | Clave de texto | En Dead Ahead (referencia) | En nuestro juego |
| --- | --- | --- | --- | --- |
| Base | `Base` | `base` | Autobús | |
| Comandante | (Fase 4) | | Bill | |
| Obstáculo objetivo | `Obstaculo` | `obstaculo` | Barricada | |
| Recurso de despliegue | `RecursoDespliegue` | `recurso_despliegue` | Courage | |
| Recurso de combate | `RecursoCombate` | `recurso_combate` | Rage | |
| Unidad | `Unidad` | `unidad.<id>` | Superviviente | |
| Enemigo | `Enemigo` | | Zombi / Marauder | |
| Poder de combate | `PoderCombate` | `poder.<id>` | Barril, molotov, granada | |

Identificadores de las unidades de arranque: `luchador_barato`, `peso_pesado`, `tirador`, `francotirador`, `apoyo`.
Identificadores de enemigos: `basico`, `horda`. Poder: `explosivo`.
